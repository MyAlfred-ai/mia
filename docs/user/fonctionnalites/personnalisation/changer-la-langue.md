## Étapes

Le sélecteur se trouve **en haut à droite de l'écran**, sur toutes les pages : un drapeau suivi du
code de la langue — **🇫🇷 FR**, **🇬🇧 EN**. Un clic ouvre la liste, un second choisit la langue. La
page se recharge aussitôt.

Sur mobile, il se réduit au drapeau, à droite du bandeau du haut.

Le même réglage se trouve aussi dans **Mon profil** (le bouton **Réglages**, en bas de la barre
latérale, y mène directement), champ **Langue de l'interface**, sous votre adresse e-mail : choisir une langue dans la liste
recharge la page de même.

## Résultat

- **Votre choix suit votre compte**, pas le navigateur : vous retrouvez votre langue sur un autre
  appareil.
- Le sélecteur fonctionne **avant même la connexion**, et le choix est conservé quand vous vous
  connectez.
- Sans choix de votre part, MIA suit la langue de votre navigateur, puis celle définie par votre
  administrateur.
- **Dates, montants et tailles** suivent la langue.
- Les pages **Assistants** et **Bases de connaissances** — listes, fiches, schémas et modèles de
  prompt — s'affichent dans la langue choisie, comme toute l'**administration** (menu, tableau de
  bord, écrans et messages).

## Ce que MIA écrit dans votre langue

- ses **réponses**, par défaut : écrivez-lui dans une autre langue, ou demandez-la, et elle vous
  suit ;
- le **titre** des nouvelles conversations, dans l'historique ;
- ce qu'elle vous **prépare** : tâches programmées, workflows, assistants, pages web.

Les assistants citent les boutons tels qu'ils s'affichent chez vous.

## Ce qui reste en français

- ce que votre organisation a rédigé : nom, description et consignes des assistants, message
  d'accueil ;
- vos contenus — titres des conversations déjà créées, messages déjà échangés, souvenirs. Ils ne
  sont jamais retraduits après coup.
