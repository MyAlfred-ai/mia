Une base que vous avez créée peut être **réservée à vous seul** : notes personnelles, dossier de
candidature, pistes de travail pas encore partageables. Ainsi réservée,
personne d'autre ne peut s'en servir — **pas même un administrateur**. C'est la visibilité
**Privée**, marquée d'un cadenas.

## Avant de commencer

- Être le **créateur** de la base. Le choix **Privée** n'est ouvert qu'à lui : un administrateur
  ne peut ni le poser sur la base de quelqu'un d'autre, ni le retirer.
- La base de l'assistant d'aide (**Système**) ne se réserve pas.

## Étapes

1. Ouvrez la fiche de la base : la tuile **Bases** de la barre latérale, cliquez la base, puis
   **Modifier**. Pour une base nouvelle, le choix est sur la fiche de création.
2. Section **Qui la voit**, choisissez **Privée** (cadenas) — « Vous seul : ni les administrateurs
   ni personne d'autre ».
3. Si la base était partagée, MIA demande confirmation : les partages accordés seront retirés.

Le choix s'enregistre seul, comme le reste de la fiche. La liste du partage se replie : il n'y a
plus rien à y régler.

## Résultat

Dans la liste des bases, la ligne de la base porte le cadenas ; dans le chat, le sélecteur de bases
l'affiche avec **Pour moi**. À partir de là :

| Qui | Ce qu'il voit |
|---|---|
| **Vous** | Tout, comme avant : la page de la base, sa fiche, les documents, le sélecteur du chat, vos assistants |
| **Les personnes et groupes à qui vous l'aviez partagée** | Plus rien : les partages sont retirés |
| **Les administrateurs** | Plus rien : ni la ligne de la liste, ni la page, ni la base dans le chat |
| **Les utilisateurs d'un assistant lié** | L'assistant répond **sans** la base — elle ne répond qu'à vous |

Dans les écrans d'ensemble de l'administration (consommation, moteur d'indexation), la base reste
comptée, sans son nom.

## Lever la réserve

Dans **Qui la voit**, choisissez **Commune** — vous et les administrateurs, puis les groupes ou
personnes que vous ajoutez — ou **Publique** — toute l'organisation. **Les anciens partages ne
reviennent pas** : ajoutez à nouveau les personnes et les groupes qui doivent y avoir accès.

## Bon à savoir

- **Une base liée à un assistant partagé** reste liée, mais ne sert qu'à vous : les autres
  utilisateurs de l'assistant obtiennent des réponses sans elle.
- **Votre compte supprimé, vos bases réservées le sont avec lui**, documents compris — comme vos
  conversations.
- **Ce que la réserve protège** : l'usage de la base dans MIA. Les personnes qui administrent le
  serveur et ses sauvegardes, elles, détiennent techniquement les données de l'instance.

## En cas de problème

| Ce qui arrive | Quoi faire |
|---|---|
| Le choix **Privée** est grisé | Vous n'êtes pas le créateur de la base : seul lui peut la réserver. |
| Un collègue ne trouve plus la base | Elle est réservée à vous seul. Passez-la en **Commune**, puis partagez-la-lui de nouveau. |
| Un assistant répond sans la base pour un collègue | Normal : une base réservée ne répond qu'à vous, même à travers un assistant. |
