MIA s'utilise dans un navigateur : l'adresse de votre organisation suffit, sur n'importe quel
appareil. Il s'installe ensuite là où vous vous en servez souvent, de deux façons — comme application
web, sur tous les appareils, ou avec l'application mobile, là où votre organisation la propose.

## Sur un ordinateur

Rien à installer. Ouvrez l'adresse de MIA de votre organisation et mettez-la en favori.

Pour l'avoir dans sa propre fenêtre, sans barre d'adresse et avec son icône : dans **Chrome** ou
**Edge**, l'icône **Installer** dans la barre d'adresse, ou le menu ⋮ → **Installer MIA**.

## Sur un téléphone ou une tablette

**Comme application web**, sur tous les appareils :

| Appareil | Comment |
|---|---|
| **Android, Chrome** | Menu ⋮ → **Ajouter à l'écran d'accueil** |
| **iPhone ou iPad, Safari** | Bouton **Partager** → **Sur l'écran d'accueil** |

**Avec l'application mobile**, quand votre organisation la propose. Ouvrez la page **`/app`** du site
depuis votre téléphone — elle est accessible sans connexion :

| Appareil | Comment |
|---|---|
| **Android** | Bouton « Télécharger l'application (APK) », puis ouvrir le fichier et autoriser l'installation. « Bientôt disponible » signifie que l'application n'est pas encore publiée sur votre instance |
| **iPhone ou iPad** | Bouton « Installer via TestFlight » si votre organisation l'a publiée, sinon l'installation comme application web ci-dessus |

Depuis un ordinateur, la page affiche des QR codes à scanner.

## Ce que l'application mobile apporte en plus

- **Connexion Google native**, avec le sélecteur de comptes du téléphone.
- **Partage natif** : les exports s'ouvrent dans la feuille de partage du téléphone.
- **Photos et caméra** directement accessibles depuis les pièces jointes.
- **Dictée et conversation vocales**, comme sur le web.
- **Connecteurs** : l'écran d'autorisation s'ouvre dans le navigateur, puis vous revenez dans
  l'application — voir [Les connecteurs](connecteurs/index.md).

L'application affiche la même interface que le site : **toutes les évolutions de MIA y apparaissent
automatiquement**, sans mise à jour. Votre session y reste ouverte **7 jours**.

## En cas de problème

| Ce qui arrive | Quoi faire |
|---|---|
| Écran « Connexion impossible » | Le serveur est injoignable — avion, zone blanche. Bouton **Réessayer**. |
| « Bientôt disponible » à la place du bouton de téléchargement | L'application n'est pas publiée sur votre instance : demandez à l'administrateur de votre organisation. |
| **Sur l'écran d'accueil** est absent du menu Partager, sur iPhone | Vous n'êtes pas dans Safari : ni Chrome ni Firefox ne posent d'icône sur iOS. |

Un compte tout juste créé peut rester bloqué à la connexion, le temps qu'un administrateur l'active :
les messages de la page de connexion sont expliqués dans [Premiers pas](../premiers-pas.md).
