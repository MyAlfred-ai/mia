Une présentation se demande **dans la conversation**, comme n'importe quelle réponse : MIA la livre
sur une **carte** que vous pouvez télécharger, retoucher à l'écran, ou faire mettre en page par un
modèle ou par Gamma. Ce qu'est un outil : [Les outils](index.md).

## Étapes

1. Écrivez votre demande en nommant le format : *« Fais-moi une présentation PowerPoint de notre offre
   pour Globex, une dizaine de slides »*. Joignez au besoin un document : il servira de source.
2. MIA rédige la présentation et la livre sur une **carte** PowerPoint : couverture, une slide par
   partie, chiffres clés, étapes, tableau, citation selon le contenu.
3. Depuis la carte :

| Bouton | Ce qu'il fait |
|---|---|
| **Télécharger** | Le fichier PowerPoint, au modèle de l'entreprise s'il y en a un ; la flèche propose aussi PDF, Word ou Markdown |
| **Modifier les slides** | Ouvre la présentation dans l'éditeur, dans le volet de droite |
| **Version soignée** | Un modèle compose lui-même le fichier, d'après votre demande, les fichiers joints à la conversation et le modèle PowerPoint de l'entreprise — une fenêtre montre le modèle choisi, ce qui part et le coût estimé avant de lancer (1 à 3 minutes, compté dans vos crédits). Si votre organisation utilise Gamma, le même bouton propose aussi **Par Gamma**. Voir [Télécharger un fichier](../conversations/telecharger-un-fichier.md#la-version-soignée-par-un-modèle-ou-par-gamma) |

Pour changer le contenu — une slide de plus, un ton plus direct —, demandez-le simplement dans la
conversation : MIA renvoie la présentation entière, sur une nouvelle carte.

## Retoucher les slides

**Modifier les slides** ouvre la présentation dans le volet de droite, directement en mode édition —
**sur ordinateur uniquement**, la retouche au doigt n'étant pas assez précise. Elle rejoint aussi la
conversation sous forme de carte de présentation, pour la rouvrir plus tard.

- **Cliquer** un élément le sélectionne, **glisser** le déplace, **tirer une poignée** le
  redimensionne. **Maj** conserve les proportions.
- Des **repères roses** signalent les alignements. **Alt** désactive cet aimant.
- **Double-cliquer** un texte permet de le réécrire sur place.
- **Suppr** retire l'élément, les **flèches** le déplacent finement, **Échap** désélectionne.
- La barre de mise en forme propose **+ Texte**, **Image**, **G**, **I**, la taille, la police et la
  couleur. La mise en forme s'applique à **toute la zone de texte**, pas à un mot isolé.
- **Image** ajoute une illustration : un fichier de votre ordinateur, ou une image générée à partir
  d'une description si un outil image vous est ouvert.

Les modifications sont enregistrées automatiquement — « Enregistré ✓ ». Le bouton **crayon** termine
la retouche ; il la reprend plus tard.

## Exporter

Depuis le volet, **Exporter** :

| Format | Ce que vous obtenez |
|---|---|
| **PowerPoint (.pptx)** | Chaque slide en objets modifiables, ouvrable dans PowerPoint, Keynote ou Google Slides. Les notes du présentateur sont conservées |
| **PDF (paysage)** | Une page 16:9 par slide |
| **Page HTML** | Un fichier autonome, images comprises |

L'export part de la présentation **telle qu'elle est enregistrée** : vos retouches y sont reprises.
Il suit la mise en page de MIA, aux couleurs de l'entreprise — pas le modèle PowerPoint de
l'entreprise : pour celui-ci, utilisez **Télécharger** sur la carte d'origine.

## Cas particuliers

**Sur mobile**, le volet s'ouvre en plein écran : consultation et exports fonctionnent, la retouche
demande un ordinateur.

**Cliquer deux fois Modifier les slides** sur la même carte rouvre la même présentation tant qu'elle
n'a pas été retouchée. Retouchée, un nouveau clic repart du texte de la carte, dans une nouvelle
présentation : vos retouches restent dans la première.

**Les présentations créées avec l'ancien outil Présentation** du menu **+** restent dans leurs
conversations : leur carte les ouvre, les retouche et les exporte comme avant.

## En cas de problème

| Ce qui arrive | Quoi faire |
|---|---|
| Pas de carte, seulement du texte | MIA n'a pas livré de fichier : redemandez en nommant le format (*« en PowerPoint »*). |
| Le crayon n'apparaît pas | La retouche demande un ordinateur : l'écran est trop petit ou tactile. |
| « Cette présentation est trop longue pour être modifiée ici… » | Demandez à MIA une version plus courte. |
| « L'éditeur de slides n'a pas pu se charger — rechargez la page. » | Rechargez la page, puis cliquez à nouveau **Modifier les slides**. |
| « Aucun outil de génération d'image n'est disponible. » | Aucun outil image ne vous est ouvert : ajoutez une image depuis un fichier, ou voyez avec un administrateur. |
