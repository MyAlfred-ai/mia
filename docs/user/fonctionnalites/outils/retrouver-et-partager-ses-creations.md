Tout ce que produisent les outils — images, vidéos, pages web, présentations, itinéraires — est
réuni dans une galerie, toutes conversations confondues. Ce qu'est un outil :
[Les outils](index.md).

## Retrouver toutes ses créations

Cliquez la tuile **Créations** de la barre latérale, dans la rangée **Espaces** : la page **Mes créations**
s'ouvre, les créations les plus récentes d'abord.

- **Rechercher** : le champ **Rechercher (titre, conversation)…** filtre sur le titre de la création
  **et** sur celui de sa conversation. La liste **Tous les types** à côté filtre par type.
- **Ouvrir** : un clic affiche la création en grand. Un itinéraire s'ouvre dans sa conversation, sur
  sa carte interactive.
- **Revenir au contexte** : **Ouvrir la conversation** ramène au fil d'origine.
- **Télécharger** : une image ou une vidéo en fichier ; une page web avec ses illustrations intégrées,
  lisible hors connexion ; une présentation en PowerPoint, PDF ou page HTML. Un itinéraire s'exporte
  depuis sa conversation, en PDF.

Les résultats des outils d'un assistant — présentations Gamma, automatisations n8n — n'y figurent
pas : ils restent dans leur conversation.

## Partager par lien

1. Sur la création — dans le chat ou dans **Mes créations** — cliquez **Partager**.
2. Le lien est **copié dans le presse-papier** : « Lien copié — visible uniquement par les
   utilisateurs connectés. » Collez-le dans un mail ou une messagerie d'équipe.
3. Le destinataire voit **uniquement la création**, avec le nom du partageur et la date. Jamais la
   conversation d'origine.

## Ce qu'il faut savoir

- **Ce n'est pas un lien public** : le destinataire doit avoir un compte sur votre instance MIA et
  être connecté. Tout compte de l'instance qui reçoit le lien peut l'ouvrir.
- Le bouton devient **Partagé**. Le recliquer ouvre un menu : **Copier le lien**, **Régénérer le
  lien** — l'ancien cesse de fonctionner — ou **Révoquer le lien**.
- Il n'y a **qu'un seul lien par création**, qu'il ait été créé depuis le chat ou depuis la galerie.
- Supprimer la conversation supprime aussi les liens de partage de ses créations.
- Sur une page web partagée, le destinataire voit la **dernière version**, retouches comprises.

## Des créations peuvent être retirées

Pour libérer de la place, votre administrateur peut **élaguer** les créations anciennes. Le texte de
l'échange est conservé, le fichier non, et son lien de partage cesse de fonctionner. **Épingler une
conversation ne protège pas ses créations.**

MIA n'est pas un espace de stockage : téléchargez depuis **Mes créations** ce qui compte pour vous.

## En cas de problème

| Ce qui arrive | Quoi faire |
|---|---|
| « Création élaguée le … » à la place d'un fichier | La création a été retirée par un élagage. Le fichier ne peut pas être récupéré ; la redemander à l'outil si besoin. |
| « Ce message ne contient aucune création partageable. » | Ce message n'a pas de création propre — une image au milieu d'une réponse d'assistant, par exemple. |
| Le destinataire arrive sur la page de connexion | Le lien exige un compte connecté sur votre instance. |
